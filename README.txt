WESTSIDEHILL ABA — WEBSITE STARTER
===================================

Files
- index.html: Homepage
- about.html: About
- services.html: Services
- families.html: Family information + FAQ
- careers.html: Careers
- contact.html: Contact form demo
- assets/style.css: Responsive visual system
- assets/script.js: Navigation, reveal effects, FAQ and demo form
- assets/bee-mark.svg: Simple editable vector mascot mark

Run locally
Open index.html in a browser, or serve this folder with a local static server.

Before launch, the client must verify and replace:
1. Official contact email, phone number, address and service area.
2. Actual services, age ranges, delivery settings and availability.
3. Staff credentials, clinical approach, intake process and any regulatory wording.
4. Privacy policy, terms, accessibility statement and required consent language.
5. Contact form integration. The current form is front-end demo only and does not send messages.
6. All photography. Current images are remote Unsplash URLs and should be replaced with licensed/client-approved images.
7. Logo/mascot. The included SVG is a starter vector interpretation, not a final approved logo.

The copy intentionally avoids unverified clinical, insurance, outcome, testimonial or credential claims.
Fonts load from Google Fonts; a system fallback is included.
